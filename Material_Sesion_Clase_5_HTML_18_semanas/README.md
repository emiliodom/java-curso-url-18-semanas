# Material — Semana 5 (formato 18 semanas · sesiones de 70 min)

**Semana 5 · Patrones de diseño y arquitectura web (MVC) · 8 de agosto de 2026**

Abrir `index.html` en el navegador (es el hub de toda la semana).

⭐ **Semana de hito:** además de la evaluación semanal normal, el entregable
de esta semana cuenta también como **Avance del Proyecto — Entrega Parcial 1**

publicada en GitHub.

## Archivos

| Archivo | Qué es |
| --- | --- |
| `index.html` | Hub/portada con navegación a todas las secciones |
| `quiz_presaberes.html` | Quiz diagnóstico de inicio (8 preguntas, autocalificado) |
| `clase.html` | Guía docente minuto a minuto: el problema de "todo mezclado", la analogía del restaurante, MVC aplicado y antipatrones |
| `ejercicios.html` | 8 ejercicios 100% de papel/diagrama (sin instalar nada) con una app de reseñas de películas (CineReseñas) |
| `cheatsheet.html` | Referencia rápida: analogía, responsabilidades por capa, antipatrones, estructura de carpetas de Spring Boot (vista previa) |
| `guia_programador_python.html` | Puente: MVC en Java/Spring vs. MVT en Python/Django — misma idea, nombres distintos |
| `challenge.html` | Juego de **clasificación** (no de secuencia): arrastra piezas de una app de préstamo de libros a su capa correcta, con retroalimentación instantánea en toasts |
| `quiz_final.html` | Quiz de final de clase (10 preguntas, evidencia de la Actividad en clase) |
| `proyecto.html` | Guía paso a paso de la **Entrega Parcial 1**: identificar Modelo/Vista/Controlador del proyecto real, diagramar y reorganizar el repositorio |
| `entregable.html` | Plantilla de la Guía de Aprendizaje 5 (cuenta también como Entrega Parcial 1) |
| `styles.css` | Estilos compartidos + reglas de impresión/PDF + componente de toasts + **tablero de clasificación MVC** (nuevo desde esta semana) |
| `quiz.js` | Motor compartido de los quizzes (copiado de la Semana 4) |
| `toast.js` | Motor compartido de notificaciones toast (copiado de la Semana 4) |

## Requisitos

- Ninguna instalación nueva — 100% conceptual y de diagrama. La implementación en
  Spring Boot empieza en la Semana 7.
- GitHub Desktop (Semana 3) y el flujo de ramas/Pull Requests (Semana 4) para publicar
  la propuesta.
- Herramienta opcional de diagramas: [draw.io](https://app.diagrams.net/) (o su
  alternativa en texto plano, ver `proyecto.html`).

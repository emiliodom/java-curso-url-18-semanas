Semana 4 · Unidad 2b — Ramas, colaboración y documentación · 1 de agosto de 2026

Material de la Sesión 4 (formato 18 semanas · 70 min)

La semana pasada tu código dejó de vivir "solo en tu computadora". Hoy aprenderás a no depender de main para cada cambio: crearás ramas (branches) para experimentar sin riesgo, propondrás tus cambios con una Pull Request, darás y recibirás retroalimentación de código, resolverás un conflicto de fusión básico y documentarás tu proyecto con un README.md profesional.

1. Quiz de Presaberes 2. Abrir guía docente 3. Abrir ejercicios
¿Cómo empiezo?
Seguimos con GitHub Desktop (sin comandos), el mismo que instalaste la semana pasada. Si necesitas repasar la instalación: Instala GitHub Desktop — Semana 3.

Aprendizajes esperados (hoy)

  • Crea y fusiona ramas (branches) para gestionar versiones.
  • Colabora en repositorios compartidos con Pull Requests.
  • Resuelve conflictos básicos de fusión (merge conflicts).
  • Documenta su proyecto con un README.md profesional.

Ruta del estudiante (70 min)

  1. Quiz de Presaberes (5 min)
  2. Clase guiada: ramas, Pull Requests y conflictos (43 min)
  3. Challenge "Ordena el flujo de colaboración" + práctica (12 min)
  4. Quiz Final + ticket de salida (10 min)
Valores de la semana: colaboración y respeto (retroalimentación constructiva al revisar código) y transparencia (documentación clara para que cualquiera entienda el proyecto).

Secciones del material

Inicio

Práctica

Consulta

Referencia rápida: crear una rama, abrir y revisar una Pull Request, fusionar, resolver un conflicto y estructura de un README profesional.

5) Puente: las ramas no son de Java

Puente

Ramas, Pull Requests y merges funcionan igual en cualquier lenguaje. Traducción de clics de GitHub Desktop a comandos.

Ir

6) Challenge — Ordena el flujo de colaboración

Juego

Arrastra las acciones al orden correcto: rama, commit, Pull Request, revisión, fusión — con un conflicto y trampas incluidas. Retroalimentación instantánea (toasts).

Ir

Ir

¿Cómo se evalúa esta semana?
Actividad en clase – Sesión 4 (quiz final + challenge, 0.66 pts) y Entrega Guía 4 (rama de desarrollo + README profesional del proyecto, 1 pt). Todo se exporta a PDF (o se comparte como enlace de GitHub) y se sube al aula virtual.
🔒 Evalúa la sesión (100% anónimo)
Al terminar la clase, cuéntanos qué funcionó, qué mejorar y cualquier queja: formulario de evaluación anónima. No se guarda tu nombre, correo ni IP.

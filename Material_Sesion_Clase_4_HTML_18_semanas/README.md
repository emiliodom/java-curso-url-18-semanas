# Material — Semana 4 (formato 18 semanas · sesiones de 70 min)

**Semana 4 · Unidad 2b — Ramas, colaboración y documentación · 1 de agosto de 2026**

Abrir `index.html` en el navegador (es el hub de toda la semana).

## Archivos

| Archivo | Qué es |
| --- | --- |
| `index.html` | Hub/portada con navegación a todas las secciones |
| `quiz_presaberes.html` | Quiz diagnóstico de inicio (8 preguntas, autocalificado) |
| `clase.html` | Guía docente minuto a minuto para la sesión de 70 min (ramas, Pull Requests, revisión y conflictos) |
| `ejercicios.html` | 8 ejercicios con **GitHub Desktop** en un repositorio de práctica (tienda de artículos deportivos), de tu primera rama a resolver un conflicto real |
| `cheatsheet.html` | Referencia rápida: crear rama, Pull Request, revisión, merge, resolver conflictos y estructura de un README profesional |
| `guia_programador_python.html` | Puente: ramas y Pull Requests son agnósticas al lenguaje — convenciones de nombres y GUI↔comandos |
| `challenge.html` | Juego drag & drop "Ordena el flujo de colaboración" con retroalimentación instantánea en toasts |
| `quiz_final.html` | Quiz de final de clase (10 preguntas, evidencia de la Actividad en clase) |
| `proyecto.html` | Guía paso a paso para aplicar todo lo anterior al **repositorio real del proyecto**: rama `development`, README profesional y primera Pull Request |
| `entregable.html` | Plantilla de la Guía de Aprendizaje 4: rama de desarrollo y README profesional del proyecto |
| `styles.css` | Estilos compartidos + reglas de impresión/PDF + componente de toasts (copiado de la Semana 3) |
| `quiz.js` | Motor compartido de los quizzes (copiado de la Semana 3) |
| `toast.js` | Motor compartido de notificaciones toast (copiado de la Semana 3) |

## Exportar a PDF

Todas las secciones tienen botón **Exportar a PDF**. Los estilos de impresión
ocultan la navegación, los botones y la pila de toasts.

## Evidencias de la semana

1. **Actividad en clase — Sesión 4 (0.66 pts):** PDF del Quiz Final + PDF del Challenge.
2. **Entrega Guía 4 (1 pt):** PDF de `entregable.html` **+ enlace real a la Pull Request** de la rama `development` del proyecto.

## Requisitos

- **GitHub Desktop** (instalado en la Semana 3) y el repositorio del proyecto ya publicado (Guía 3).
- Cuenta gratuita en [GitHub](https://github.com).
- Plan B si una Pull Request no carga o falta conectividad: [Learn Git Branching](https://learngitbranching.js.org/?locale=es_ES) (simulador en el navegador, en español) para practicar el concepto de ramas y merge.

> El material funciona offline salvo Bootstrap (CDN) y los enlaces a GitHub/Learn Git Branching.

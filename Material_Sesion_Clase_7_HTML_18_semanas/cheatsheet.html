Referencia rápida — Initializr, estructura y comandos

Dos pestañas: conceptos (qué es cada cosa) y comandos + solución de problemas (para cuando algo no arranca).

A. Piezas del rompecabezas — qué hace cada una

PiezaQué esAnalogía
JDKCompila y ejecuta código JavaEl motor del carro
VS Code + extensión JavaDonde escribes y ejecutas el códigoEl tablero de controles
MavenDescarga dependencias y empaqueta el proyecto, según pom.xmlEl repartidor que trae las piezas que pediste
Maven Wrapper (mvnw)Una copia de Maven incluida en el proyecto — no hace falta instalar Maven aparteTraer tu propia herramienta en la caja
Spring InitializrGenera el esqueleto del proyecto según los parámetros que elijasLa plantilla de un formulario ya armado
Spring BootEl framework: trae un servidor web (Tomcat) embebido y configuración automáticaLa cocina ya equipada, no hay que instalar cada aparato por separado

C. Estructura generada — para qué sirve cada archivo

mi-proyecto/
├── mvnw, mvnw.cmd                    ← Maven Wrapper (no instalar Maven aparte)
├── pom.xml                           ← dependencias + versión de Java
└── src/
    ├── main/java/.../MiProyectoApplication.java   ← @SpringBootApplication + main()
    ├── main/resources/application.properties      ← configuración (clave=valor)
    ├── main/resources/static/                     ← archivos públicos (imágenes, CSS) — semanas futuras
    ├── main/resources/templates/                  ← vistas Thymeleaf — desde la Semana 10
    └── test/java/...                              ← pruebas automáticas — semanas futuras

D. application.properties — lo que hoy sí toca

# cambia el puerto (por defecto es 8080)
server.port=8081

# le da un nombre a tu aplicación (aparece en los logs)
spring.application.name=mi-proyecto
Es un archivo de configuración simple: una línea por cada clave=valor. Semana a semana se irá llenando con más configuración (base de datos, seguridad, etc.).

F. Confusiones frecuentes

ConfusiónAclaración
"¿Tengo que instalar Maven?"No. Spring Initializr incluye mvnw/mvnw.cmd, una copia lista para ese proyecto.
"La página de error (Whitelabel) significa que algo salió mal"No necesariamente: significa que el servidor está corriendo pero aún no tiene ninguna ruta definida (eso llega en la Semana 8).
"¿Por qué no agregamos Spring Data JPA de una vez?"Cada dependencia se agrega cuando toca su tema, para entender bien qué hace cada una antes de mezclarlas.
"¿Cuántas veces puedo generar un proyecto en Initializr?"Las que necesites — es un formulario gratuito y sin límite, no crea nada hasta que pulsas "Generate".
Antes de estos comandos
Todos se escriben en la terminal integrada de VS Code (menú Terminal → New Terminal), estando dentro de la carpeta del proyecto generado.

Comandos de verificación

java -version           # confirma el JDK
javac -version          # confirma el compilador
code --version          # confirma VS Code

Ejecutar el proyecto por terminal

# Windows
mvnw spring-boot:run

# Mac/Linux
./mvnw spring-boot:run

# Detener: Ctrl + C en la misma terminal

Extensiones de VS Code necesarias hoy

1
Extension Pack for Java (Microsoft)
Ya la tenías desde la Semana 1 — Paso 3. Confirma que siga "Installed".
2
Spring Boot Extension Pack (VMware / Microsoft)
Nueva esta semana: icono de Extensiones → busca "Spring Boot Extension Pack" → Install. Agrega soporte para application.properties (autocompletado) y para generar proyectos desde VS Code.
Solución de problemas frecuentes
Mensaje / síntomaQué significaQué hacer
Web server failed to start. Port 8080 was already in use.Ya hay otro proceso usando ese puerto (a veces, otra copia tuya que quedó corriendo)Detén el proceso anterior (Ctrl+C en su terminal) o cambia server.port en application.properties.
El botón "▶ Run" no aparece sobre mainLa extensión de Java no detectó el proyecto como Java/MavenVerifica que abriste la carpeta raíz del proyecto (la que tiene pom.xml), no una subcarpeta.
"java: command not found" al ejecutar mvnwEl JDK no está en el PATHRepite Semana 1 — Paso 2 (troubleshooting T1).
La descarga de dependencias tarda mucho la primera vezMaven está descargando las piezas de Spring Boot por primera vez (se guardan en caché)Es normal solo la primera vez; espera con conexión estable. Las siguientes ejecuciones serán rápidas.
No tengo permisos/tiempo para instalar nada en esta computadora—Usa el Plan B de la Semana 1 (compilador en línea) mientras resuelves tu entorno real — Spring Boot exige JDK local, así que no es sustituto definitivo.
¿Todo listo?
Si viste la línea Started ... Application in X seconds en tu terminal y localhost:8080 respondió con algo (aunque sea la Whitelabel Error Page), tu entorno está completamente listo para la Semana 8.

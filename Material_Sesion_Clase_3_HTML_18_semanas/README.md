## Requisitos

- **GitHub Desktop** (`instalacion_github_desktop.html`) — ruta principal, sin comandos — **o** Git por línea de comandos (ver `../Material_Sesion_Clase_1_HTML_18_semanas/instalacion.html`, Paso 4, y el `anexo_comandos.html` de esta carpeta).
- Cuenta gratuita en [GitHub](https://github.com).
- Plan B si ni siquiera eso se puede instalar hoy: [Learn Git Branching](https://learngitbranching.js.org/?locale=es_ES) (simulador en el navegador, en español).

> El material funciona offline salvo Bootstrap (CDN) y los enlaces a GitHub/Learn Git Branching.

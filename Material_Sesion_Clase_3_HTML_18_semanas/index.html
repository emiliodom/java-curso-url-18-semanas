Semana 3 · Unidad 2a — Git y GitHub: control de versiones · 25 de julio de 2026

Material de la Sesión 3 (formato 18 semanas · 70 min)

Hoy tu código deja de vivir "solo en tu computadora". Aprenderás Git (el sistema de control de versiones) y GitHub (dónde vive tu código en línea): el flujo básico init → add → commit → push y cómo conectar tu repositorio local con uno remoto.

1. Quiz de Presaberes 2. Abrir guía docente 3. Abrir ejercicios
¿Cómo empiezo?
Esta semana se trabaja con GitHub Desktop (sin comandos): crea tu cuenta de GitHub, instala la app y listo. ¿Ya tienes soltura con la terminal? El Anexo: Comandos tiene el mismo flujo con git.

Aprendizajes esperados (hoy)

  • Instala y configura Git en su entorno de trabajo.
  • Realiza commits y gestiona el historial de cambios.
  • Comprende la importancia del versionamiento en proyectos.
  • Conecta un repositorio local con uno remoto en GitHub.

Ruta del estudiante (70 min)

  1. Quiz de Presaberes (5 min)
  2. Clase guiada: conceptos, flujo básico y remoto (43 min)
  3. Challenge "Ordena el flujo Git" + práctica (12 min)
  4. Quiz Final + ticket de salida (10 min)
Valores de la semana: orden y trazabilidad (mensajes de commit significativos) y seguridad colaborativa (el control de versiones protege tu progreso ante errores o pérdidas).

Challenge · Ordena el flujo Git · Semana 3 · Con GitHub Desktop

Arrastra cada acción a su lugar correcto

Un flujo de GitHub Desktop desordenado. Cada vez que sueltas una pieza recibes retroalimentación inmediata (arriba a la derecha). También puedes usar clic para tomar → clic para soltar en tablet o celular.

Cómo jugar

  1. Elige un nivel: Fácil → Medio → Difícil.
  2. Lee la misión: qué flujo de GitHub Desktop debes reconstruir.
  3. Arrastra las acciones del banco a las líneas numeradas (o tócalas: primero la acción, luego el destino).
  4. Cada suelta te avisa al instante si vas bien, si el paso va antes/después, o si la acción no es válida.
  5. Cuando todas las líneas estén en verde, pulsa Verificar para tu puntaje final.
  6. Al terminar: escribe tu nombre y Exportar a PDF.
Ojo en Medio y Difícil
Hay acciones trampa: se ven parecidas a las correctas pero son un botón que no existe, un orden ilógico, o algo destructivo. Déjalas en el banco.

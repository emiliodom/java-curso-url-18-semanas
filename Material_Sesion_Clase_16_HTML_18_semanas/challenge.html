Detective de QA: Diagnostica 4 Escenarios de Fallo

Un tester profesional no solo reporta que "no funciona": identifica con precisión la causa raíz en la arquitectura.

Caso 1

Al ingresar por URL a /donaciones sale la Whitelabel Error Page (404 Not Found).

Caso 2

El usuario envía el formulario con un campo obligatorio vacío. La página se refresca pero todos los campos se borran.

Caso 3

La app funciona perfecto en localhost con H2, pero en Render lanza PSQLException: Connection refused al arrancar.

Caso 4

Hiciste cambios en formulario.html, ejecutaste git commit y git push origin main, pero el deploy en Render falló en Maven.

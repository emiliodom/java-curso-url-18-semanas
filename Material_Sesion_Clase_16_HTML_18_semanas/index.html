Domina tu arquitectura y asegura la calidad (70 min)

Para probar y mantener una aplicación web con rigor, primero debes comprender su estructura íntima. Hoy reforzamos el árbol del proyecto, los archivos clave y el circuito completo del dato (Formulario ↔ Controlador ↔ Modelo ↔ Repositorio), ejecutamos una matriz de QA profesional y comprobamos el ciclo automático cambio → push → redeploy en Render.

1. Quiz de Presaberes 2. Matriz de Pruebas QA 3. Reporte de Mantenimiento
🎯 Enfoque pedagógico de refuerzo
Sin librerías nuevas: consolidamos los fundamentos que causan confusión (paquetes vs carpetas, binding en formularios, inyección de repositorios y depuración de errores) antes del hito de entrega de la Semana 17.

Aprendizajes esperados

  • Reconoce la ubicación y propósito de cada archivo del árbol de Spring Boot.
  • Rastrea el ciclo de una petición HTTP desde el formulario hasta la base de datos Neon.
  • Diseña y ejecuta casos de prueba funcionales (QA) con severidad y evidencias.
  • Comprueba el ciclo de mantenimiento continuo: git push → redeploy automático en Render.

Ruta de la sesión (70 min)

  1. Presaberes + Diagnóstico del árbol (8 min)
  2. El viaje del dato: Formulario ↔ Controlador ↔ Repositorio (22 min)
  3. Diseño y ejecución de matriz QA (20 min)
  4. Ciclo cambio → push → redeploy en Render (10 min)
  5. Challenge interactivo y Quiz Final (10 min)

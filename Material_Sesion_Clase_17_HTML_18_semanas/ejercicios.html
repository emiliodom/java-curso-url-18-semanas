Guion y Preparación para la Demostración en Vivo

Aprender a presentar software es tan importante como programarlo. Sigue este guion estructurado de 4 minutos para que tu exposición sea fluida, técnica y convincente.

El Guion de 4 Minutos Paso a Paso

4:00 Minutos Exactos
Minuto 0:00–1:00 · El Problema y la Arquitectura 60 segundos

Qué decir: «Buenas tardes. Nuestro proyecto atiende a [Nombre de la Entidad sin Fines de Lucro], una institución que [describir brevemente su misión y el problema de registro que tenían]. Para solucionarlo, construimos una aplicación web en Java con Spring Boot bajo una arquitectura en capas MVC.»

Qué mostrar: Tu diapositiva de portada o el README.md en GitHub mostrando el diagrama de capas (Modelo, Controlador, Repositorio, Vistas).

Minuto 1:00–2:15 · Formulario, Validación y UX 75 segundos

Qué decir: «El personal registra a los beneficiarios a través de este formulario en Thymeleaf. Para evitar datos corruptos, aplicamos Bean Validation estricto.»

Qué mostrar: Presiona "Guardar" dejando campos vacíos. Muestra cómo aparecen las alertas en rojo y cómo los datos previos se retienen. Luego ingresa un registro real y presiona "Guardar".

Detalle técnico a destacar: «Observen cómo aplicamos el patrón POST-Redirect-GET: si refresco la pantalla con F5, no se duplica ningún registro.»

Minuto 2:15–3:15 · Persistencia en Neon y Listado 60 segundos

Qué decir: «La información viaja a través de Spring Data JPA y se almacena en nuestra base de datos PostgreSQL gestionada en Neon en la nube con conexión cifrada SSL.»

Qué mostrar: El nuevo registro apareciendo en la tabla dinámica del listado principal con sus datos formateados.

Minuto 3:15–4:00 · Seguridad por Roles y Despliegue 45 segundos

Qué decir: «Implementamos Spring Security con contraseñas encriptadas con BCrypt y roles diferenciados: los usuarios comunes pueden registrar y consultar, mientras que solo el rol ADMIN tiene acceso a eliminar registros o ver auditorías.»

Qué mostrar: Cierra sesión e intenta acceder a una ruta protegida para mostrar la redirección al login, o inicia sesión como ADMIN para mostrar los botones autorizados.

Cheat Sheet · Semana 8 · @RestController y tu primer formulario

Referencia rápida — anotaciones, comandos y un adelanto

Tres pestañas: conceptos y código de hoy, comandos + solución de problemas, y un Anexo opcional con un adelanto (sin implementar todavía) de estilo y guardado real en base de datos.

A. Código completo de hoy: controlador + formulario

src/main/java/.../BienvenidaController.java:

@RestController
public class BienvenidaController {

    @GetMapping("/api/saludo")
    public String saludo() {
        return "¡Bienvenido(a) al Comedor Solidario Manos Unidas!";
    }

    @GetMapping("/api/bienvenida")
    public String bienvenida(@RequestParam(defaultValue = "visitante") String nombre) {
        return "Hola, " + nombre + ". Gracias por apoyar al Comedor Solidario Manos Unidas.";
    }
}

src/main/resources/static/index.html:

<!doctype html>
<html lang="es">
<head>
  <meta charset="utf-8" />
  <title>Comedor Solidario Manos Unidas</title>
</head>
<body>
  <h1>Comedor Solidario Manos Unidas</h1>
  <form id="formBienvenida">
    <label for="nombre">Tu nombre:</label>
    <input type="text" id="nombre" name="nombre" required />
    <button type="submit">Enviar saludo</button>
  </form>
  <p id="resultado"></p>

  <script>
    document.getElementById('formBienvenida').addEventListener('submit', function (e) {
      e.preventDefault();
      var nombre = document.getElementById('nombre').value;
      fetch('/api/bienvenida?nombre=' + encodeURIComponent(nombre))
        .then(function (respuesta) { return respuesta.text(); })
        .then(function (texto) { document.getElementById('resultado').textContent = texto; });
    });
  </script>
</body>
</html>

B. Anotaciones de hoy

AnotaciónQué hace
@RestControllerMarca la clase como un controlador que devuelve datos directamente (texto/JSON), sin pasar por una vista HTML del lado del servidor.
@GetMapping("/ruta")Conecta una URL exacta con un método Java, solo para peticiones HTTP GET.
@RequestParamLee un valor que viene después del ? en la URL (ej. ?nombre=Ana) y lo entrega como parámetro del método.
@RequestParam(defaultValue = "...")Da un valor por defecto si el parámetro no viene en la URL, evitando errores.

C. ¿Dónde va cada archivo?

mi-proyecto/
└── src/main/
    ├── java/.../BienvenidaController.java   ← tu nueva clase @RestController
    └── resources/
        ├── application.properties           ← configuración (Semana 7)
        └── static/index.html                ← formulario servido automáticamente en "/"
Todo lo que pongas dentro de static/ se sirve tal cual, sin procesar — es HTML, CSS y JavaScript normales. No necesitas configurar nada extra para que Spring Boot lo encuentre.

D. Qué SÍ toca hoy y qué NO (para no adelantarse)

✅ Semana 8 (hoy)
@RestController, rutas @GetMapping, @RequestParam, un formulario HTML estático con fetch que consulta el endpoint (sin guardar nada), probar con navegador y Postman.
⏭ Todavía no
Guardar datos (@PostMapping con persistencia) · vistas con Thymeleaf (Semana 10) · base de datos con JPA (Semana 12). Un adelanto sin implementar está en la pestaña "Anexo".

E. Confusiones frecuentes

ConfusiónAclaración
"Mi formulario recarga la página y no muestra nada"Falta e.preventDefault() en el submit, o el fetch tiene un error de sintaxis — revisa la consola del navegador (F12).
"¿index.html de static/ es lo mismo que Thymeleaf?"No. Es un archivo estático fijo; Thymeleaf (Semana 10) genera HTML dinámico desde el servidor con datos de Java.
"¿Por qué el método devuelve String y no JSON?"Para mantenerlo simple hoy. @RestController también puede devolver objetos que se convierten en JSON automáticamente — lo verás cuando el proyecto crezca.
"Cambié el código pero el navegador muestra lo de antes"Reinicia el proyecto (⏹ y ▶ Run de nuevo) y refresca con Ctrl+F5 para evitar la caché del navegador.
Antes de estos comandos
Todos se escriben en la terminal integrada de VS Code, estando dentro de la carpeta del proyecto. El servidor debe estar corriendo para probar cualquier ruta.

Ejecutar y detener el proyecto

# Windows
mvnw spring-boot:run

# Mac/Linux
./mvnw spring-boot:run

# Detener: Ctrl + C en la misma terminal

Probar una ruta GET desde la terminal (alternativa a Postman)

curl "http://localhost:8080/api/bienvenida?nombre=Ana"
Útil si no quieres instalar nada adicional: curl ya viene incluido en la terminal de Windows 10/11, macOS y Linux.

Adelanto 1 — Dar estilo a tu formulario (esto SÍ lo puedes hacer hoy)

A diferencia de la base de datos, darle estilo a static/index.html no depende de ningún tema futuro — es CSS normal, como en cualquier página web. Puedes agregar un archivo static/estilos.css:

body { font-family: system-ui, sans-serif; max-width: 480px; margin: 3rem auto; padding: 0 1rem; }
h1 { color: #0b3d91; }
form { display: flex; gap: 0.5rem; margin-top: 1rem; }
input { flex: 1; padding: 0.5rem; }
button { padding: 0.5rem 1rem; }
#resultado { margin-top: 1rem; font-weight: 600; }

Y enlazarlo dentro del <head> de tu index.html: <link rel="stylesheet" href="estilos.css" />. Spring Boot lo sirve automáticamente, igual que el HTML.

Adelanto 2 — Cómo se vería con guardado real en base de datos (Semana 12, NO lo hagas hoy)

Cuando el curso llegue a JPA (Semana 12), el mismo formulario podría enviar sus datos a un endpoint que sí los guarde de verdad, con una anotación nueva (@PostMapping) y una entidad conectada a una base de datos:

// Vista previa — todavía NO existe "Entidad" ni base de datos en tu proyecto
@PostMapping("/api/visitas")
public Visita registrarVisita(@RequestBody Visita visita) {
    return visitaRepository.save(visita); // guardado real — llega en la Semana 12
}
Hoy tu formulario usa GET y solo consulta — nada se guarda entre una visita y otra del navegador. @PostMapping, @RequestBody y save() son piezas que se explican formalmente cuando lleguen su tema (rutas de guardado en la Semana 10, persistencia en la Semana 12).
Por qué no lo hacemos todavía
Igual que con Thymeleaf y JPA la semana pasada: cada pieza se agrega cuando toca su tema, para entenderla bien antes de mezclarla con las demás. Adelantar @PostMapping o una base de datos hoy generaría más confusión que aprendizaje.

Obligatorio = dos candados: @NotBlank/@NotNull (valida en la aplicación y muestra el mensaje) y @Column(nullable = false) (lo exige la base). Un campo opcional lleva solo @Column sin nullable = false.

🎯 Banco conceptual de la Sesión 15 (Presaberes y Quiz Final)
Aquí tienes un resumen de estudio rápido con todas las preguntas y aprendizajes evaluados en el Quiz interactivo. Está dividido en tres bloques: repaso de fundamentos (Presaberes), seguridad en producción (Núcleo) y transformación hacia el proyecto propio (Quiz Final).
🟡 Bloque 1: Presaberes — Repaso de persistencia, roles y variables (Semanas 12–14)
Concepto / Pregunta evaluada Respuesta correcta Justificación técnica / Clave de aula
¿Por qué DB_PASSWORD vive en variables de entorno? Porque el código se publica en GitHub y cualquiera podría leer la clave. El código fuente es público. Las variables de entorno inyectan secretos desde el host (Render) sin guardarlos en el repositorio.
¿Para qué sirven dos perfiles (dev y prod)? Para usar H2 en local y PostgreSQL (Neon) en internet con exactamente el mismo código. Misma aplicación y lógica de negocio, diferente infraestructura y destino de base de datos según el entorno de ejecución.
¿Qué significa almacenar contraseñas con BCrypt? Se almacena un resumen criptográfico irreversible (hash) y no la contraseña en texto plano. Si un atacante accede a la tabla usuario, no puede revertir el hash para obtener la contraseña original de las personas.
¿Qué pasa si un ENTRENADOR escribe /jugadores/nuevo a mano? Recibe un error 403 (Acceso denegado). La seguridad real está en las reglas del servidor (SecurityConfig), no en ocultar enlaces en el HTML.
Comportamiento de ddl-auto=update al agregar campos Agrega nuevas tablas y columnas a la base, pero nunca renombra ni elimina columnas previas. Hibernate amplía el esquema de forma aditiva. Es práctico en clase, pero requiere precaución con datos antiguos.
Diferencia: @NotBlank vs. @Column(nullable = false) @NotBlank valida en la app y genera el mensaje de error; nullable=false lo exige la base de datos. Doble candado defensivo: la validación en Bean Validation da una respuesta amigable al usuario; la restricción SQL protege la integridad relacional.
🌐 Bloque 2: Núcleo — Seguridad básica, HTTPS, Neon SSL y Protecciones Web (Presaberes y Final)
Concepto / Pregunta evaluada Respuesta correcta Justificación técnica / Clave de aula
¿Quién provee el candado HTTPS en *.onrender.com? Render, automáticamente y sin costo mediante certificados SSL gestionados. No hay que configurar certificados manualmente; el rol como desarrollador es verificar y auditar que esté activo.
¿Qué garantiza sslmode=require en DB_URL? Que todo el tráfico entre la aplicación Spring Boot y Neon viaje estrictamente cifrado. Es el "sobre sellado" de la conexión JDBC hacia PostgreSQL; Neon además rechaza cualquier intento de conexión insegura.
¿Qué es el campo oculto _csrf en los formularios? Un token único («sello») que demuestra que el envío proviene legítimamente de nuestra propia página. Protege contra Cross-Site Request Forgery (CSRF). Thymeleaf lo inserta automáticamente al usar th:action.
¿Cuándo tendría sentido desactivar CSRF? Únicamente en una API REST pura sin sesión ni cookies (autenticada por tokens tipo Bearer). En aplicaciones web tradicionales con cookies de sesión y formularios Thymeleaf, desactivar CSRF es una vulnerabilidad grave.
Entrada maliciosa <script> renderizada con th:text Se visualiza como texto plano seguro porque Thymeleaf escapa caracteres < y >. Mitiga el ataque Cross-Site Scripting (XSS). La vulnerabilidad ocurriría si se usara indebidamente th:utext.
Propósito de la cabecera X-Frame-Options: DENY Impide que sitios externos incrusten nuestra página dentro de un <iframe> ajeno. Protección contra clickjacking (superposición de interfaces invisibles para engañar clics del usuario).
Tipo de dato para códigos como ISBN o DPI String (texto con patrón de validación). No se operan aritméticamente, pueden iniciar con cero y llevan guiones. Un Integer destruiría el formato.
Tipo de dato para dinero y precios con decimales BigDecimal (con step="0.01" en el HTML). Evita errores de redondeo en punto flotante que sufriría un Double en transacciones contables.
🔴 Bloque 3: Quiz Final — Adaptación al proyecto propio, páginas, rutas y parámetros
Concepto / Pregunta evaluada Respuesta correcta Justificación técnica / Clave de aula
Error: contains null values al desplegar en Neon Se agregó una columna nullable=false a una tabla que ya tenía registros. Solución: vaciar la tabla de pruebas en Neon antes del deploy o definir temporalmente la columna como opcional.
Formulario con action="/libros" devuelve 403 Forbidden Falta la sintaxis th:action="@{/libros}" de Thymeleaf, omitiendo el token _csrf. Spring Security bloquea cualquier petición POST que no presente un token CSRF válido asociado a la sesión.
Página /creditos redirige inesperadamente al login No fue agregada a la lista permitAll() en SecurityConfig. Por defecto, anyRequest().authenticated() intercepta y exige sesión para cualquier ruta no exenta explícitamente.
Ficha detallada de un registro específico (/libros/7) @GetMapping("/libros/{id}") capturado mediante @PathVariable Long id. El identificador único del recurso forma parte integral de la ruta canónica.
Filtrado opcional en URL: /buscar?genero=Novela @RequestParam(defaultValue = "") String genero. Los criterios de búsqueda/filtrado viajan tras el signo ? (query string) y deben contemplar valores por omisión.
Renombrar la clase Jugador a Libro en producción Hibernate crea la tabla libro vacía; los datos viejos permanecen intactos en la tabla jugador. ddl-auto=update solo crea tablas nuevas; no sabe inferir un renombramiento estructural entre entidades.
Cambiar rutas a /libros sin ajustar SecurityConfig Las nuevas rutas pierden la regla restrictiva de rol (ADMIN) y quedan abiertas a cualquier usuario logueado. Las autorizaciones dependen de patrones de URL explícitos (ej. /libros/**); si no coinciden, caen en la regla general.
¿Por qué el buscador usa GET y el registro usa POST? Lectura = GET (segura, idempotente y almacenable en enlaces); Modificación = POST (requiere protección CSRF). Estándar HTTP: nunca usar GET para mutar el estado o persistir datos en la base de datos.
Visualización de fichas de 10–15 campos en la lista web Mostrar únicamente 3 a 4 columnas identificativas; el resto se reserva para la vista de detalle o edición. Una tabla con 15 columnas colapsa la experiencia visual y la usabilidad móvil.
Mapeo de fechas de ingreso o recepción Tipo LocalDate en Java acompañado de un input type="date" en HTML. Estandariza fechas en formato ISO-8601 (YYYY-MM-DD) previniendo confusiones culturales entre día y mes.
Significado del «congelamiento de características» (feature freeze) No se admiten dependencias ni funciones adicionales; el foco es migrar, auditar, probar y estabilizar el proyecto. Permite que los alumnos con rezago alcancen la meta de entrega sin dispersión técnica innecesaria.
